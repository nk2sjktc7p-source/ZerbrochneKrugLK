KRUG LK – PWA

GitHub Pages:
1. Neues öffentliches GitHub-Repository anlegen, z. B. krug-lk.
2. Alle Dateien aus diesem Ordner in die oberste Ebene des Repositorys hochladen:
   index.html
   manifest.webmanifest
   service-worker.js
   icon-192.png
   icon-512.png
3. Repository: Settings > Pages.
4. Unter Build and deployment: Deploy from a branch.
5. Branch: main, Ordner: /(root), Save.
6. Nach kurzer Zeit erscheint die GitHub-Pages-Adresse.

iPhone/iPad:
Die veröffentlichte Adresse in Safari öffnen > Teilen > Zum Home-Bildschirm.
Danach startet die Lernplattform wie eine eigenständige App.
Nach dem ersten vollständigen Laden steht sie durch den Service Worker auch offline zur Verfügung.
